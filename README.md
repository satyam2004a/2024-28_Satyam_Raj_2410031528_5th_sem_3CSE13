## 📌 About the Internship

The **Data Science Master Virtual Internship** provided structured, practical learning focused on Data Science fundamentals and real-world dataset analysis.

The internship covered **data collection, loading, cleaning, preprocessing, exploratory data analysis, visualization, statistical analysis, data-quality assessment, anomaly detection, and basic machine learning concepts**.

The program combined conceptual learning with hands-on activities, developing practical skills in Python-based data analysis, dataset handling, visualization, and problem-solving.

**Organization:** EduSkills Academy — an ISO 9001:2015 and ISO/IEC 20000-1:2018 certified organization working under the theme **“Nation Building Through Skills”**, in partnership with AICTE under the AICTE–EduSkills Virtual Internship Program.
